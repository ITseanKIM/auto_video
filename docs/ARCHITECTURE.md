# 투데이즈 오디오 스튜디오 웹 전환 설계

## 목표

Windows 단일 사용자 프로그램의 제작 파이프라인을 여러 사용자가 안전하게 이용하는 웹 서비스로 전환한다.

`소재 → 아웃라인 → 대본 → 음성 → 장면 이미지 → 자막/음향 → 렌더 → 업로드 패키지`

## 실행 경계

- **Vercel / Next.js**: 인증, 프로젝트 CRUD, 설정, 작업 요청, 진행 상태, 결과 다운로드
- **Supabase**: 사용자별 데이터, 작업 상태, 사용량, RLS, 결과 메타데이터
- **Object Storage**: 음성, 이미지, 오버레이, 완성 영상
- **Queue**: 단계별 작업 전달, 재시도, 취소, 이어서 실행
- **Worker**: Python TTS와 FFmpeg를 실행하는 장시간 작업 서버

Vercel 함수에서는 FFmpeg 렌더와 로컬 TTS를 실행하지 않는다. 함수는 작업을 큐에 넣고 즉시 작업 ID를 반환한다.

## 기존 프로그램에서 확인한 구성

- Electron + Express 5 + SQLite
- OpenAI, Gemini, Claude 대본 공급자
- OpenAI, Gemini 이미지 공급자
- Supertonic 3, Qwen3-TTS 음성 엔진
- FFmpeg 렌더, Freesound 음향 검색
- SSE 진행 이벤트
- 에피소드, 장면, 대사, 이미지 슬라이드, 보이스 프리셋 데이터 모델

## 웹판 개선점

1. 모든 레코드와 저장 파일에 `user_id` 또는 `project_id`를 부여한다.
2. API 키는 브라우저나 DB 평문에 저장하지 않고 서버 암호화 또는 외부 비밀 저장소를 사용한다.
3. 각 단계는 멱등 작업으로 만들고 완료 산출물이 있으면 중복 생성하지 않는다.
4. 장면 하나만 다시 생성할 수 있게 대본, 음성, 이미지를 독립 작업으로 나눈다.
5. Provider 인터페이스로 모델 교체와 장애 시 대체 공급자를 지원한다.
6. 사용량과 예상 비용을 프로젝트 및 단계별로 기록한다.
7. 보이스 클론에는 동의 확인 기록과 원본 삭제 기능을 둔다.

## 단계 상태

`draft → outlining → scripting → voicing → illustrating → composing → completed`

각 단계는 `queued | running | succeeded | failed | cancelled` 작업을 별도로 가진다. 실패한 단계부터 재개할 수 있다.

## 초기 구현 순서

1. 프로젝트 생성과 사용자별 목록
2. 대본 생성 및 장면 편집
3. TTS 작업 서버 연결과 음성 미리듣기
4. 이미지 생성과 장면별 재생성
5. FFmpeg 렌더 작업
6. 결과 다운로드와 유튜브 업로드 패키지
7. 사용량 제한, 결제, 팀 기능
